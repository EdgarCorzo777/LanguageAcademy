# Academic Programs & Level Structure

## 1. Available Academic Programs

### 1.1 AI Engineering Program
- **Overview**: Hands-on specialization in Large Language Models (LLMs), RAG pipelines, Agentic workflows, Vector Databases, Python backend engineering, and MLOps.
- **Duration**: 16 weeks (480 total instructional and project hours).
- **Core Technologies**: Python, FastAPI, LangChain, LlamaIndex, ChromaDB, HuggingFace, Docker, Git.

### 1.2 Full-Stack Web Development Program
- **Overview**: Complete full-stack engineering curriculum focusing on scalable web architectures, modern frontend frameworks, and cloud-ready RESTful APIs.
- **Duration**: 16 weeks (480 total instructional and project hours).
- **Core Technologies**: TypeScript, React, Next.js, Node.js, Express, PostgreSQL, Prisma, Docker.

### 1.3 Data Science & Analytics Program
- **Overview**: Data engineering pipelines, exploratory data analysis, statistical modeling, machine learning, and business intelligence dashboards.
- **Duration**: 16 weeks (480 total instructional and project hours).
- **Core Technologies**: Python, Pandas, NumPy, Scikit-Learn, SQL, Power BI, Tableau.

### 1.4 Cloud & Cybersecurity Program
- **Overview**: Infrastructure as Code, Cloud Architecture, CI/CD pipelines, penetration testing basics, and DevSecOps practices.
- **Duration**: 16 weeks (480 total instructional and project hours).
- **Core Technologies**: AWS, Azure, Linux, Terraform, Kubernetes, Docker, Bash.

---

## 2. Program Level Breakdown

### Level 1: Foundations & Core Concepts (Weeks 1 to 4)
- Focus: Programming foundations, version control with Git/GitHub, algorithmic problem solving, clean code principles, and development environment setup.
- Target Audience: Beginners or self-taught developers needing solid engineering foundations.

### Level 2: Core Engineering & Architecture (Weeks 5 to 10)
- Focus: Advanced frameworks, database management, API design, testing paradigms, and domain-specific concepts (e.g., embeddings and vector search in AI).
- Milestone: Mid-term portfolio capstone project.

### Level 3: Advanced Applications, Production & Capstone (Weeks 11 to 16)
- Focus: Microservices, production deployment, CI/CD, performance optimization, security, and enterprise team capstone project.
- Milestone: Final capstone demo presented to industry hiring partners.

---

## 3. Prerequisites by Program
- **AI Engineering**: Basic programming knowledge in Python or another modern object-oriented language. High school level mathematics.
- **Full-Stack Web Development**: No prior coding experience required; basic computer literacy and problem-solving readiness.
- **Data Science**: Basic knowledge of spreadsheets and basic arithmetic/algebra.
- **Cloud & Cybersecurity**: Basic understanding of computer networking and operating systems.
